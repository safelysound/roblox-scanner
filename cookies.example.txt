# ROBLOSECURITY cookie pool — example only, NEVER commit real cookies.
#
# The scanner reads cookies from environment variables (in this priority order):
#   ROBLOX_COOKIE, ROBLOSECURITY, ROBLOSECURITY_1 ... ROBLOSECURITY_6
# In GitHub Actions, set them as repository secrets with those names.
# Locally, export them in your shell instead of using a file:
#
#   export ROBLOSECURITY_1="_|WARNING:-DO-NOT-SHARE-THIS...|REPLACE_ME"
#   export ROBLOSECURITY_2="_|WARNING:-DO-NOT-SHARE-THIS...|REPLACE_ME"
#   python tracker_scanner.py --tracker developers --max-members 10 --verbose
#
# How to get a cookie: log in to Roblox, open DevTools (F12) -> Application -> Cookies
# -> https://www.roblox.com -> copy the value of .ROBLOSECURITY.
#
# More cookies = more presence requests per minute. One cookie works; extras just spread the load.
